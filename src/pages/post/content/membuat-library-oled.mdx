## Datasheet

Langkah awal adalah mencari rujukan dimana kita bisa mendapatkan informasi yang kita perlukan, *datasheet* adalah kitab yang kita perlukan untuk membedah oled 1.3 inch.

secara umum display oled adalah matrix dari pixel, jika ukuran 1.3 inch maka pixelnya adalah sebanyak **128x64** dimana sejumlah 128 kolom dan 64 baris

tentunya pixel tersebut harus dikontrol dengan sebuah *Chip* atau IC, dalam hal ini *Chip* tersebut seringkali disebut sebagai **Controller** (karena chip ini yang akan mengontrol pixel matrix).

### Alamat - *Address*

sudah tidak asing lagi ya untuk temen-temen yang pernah pake modul yang menggunakan komunikasi i2c dan bahkan ketika menggunakan library pun biasanya kita harus memasukkan *address* atau alamat dari modul yang kita gunakan.

Singkatnya, dalam komunikasi I2c terdapat konsep *Master* dan *Slave*, sesuai dengan penamaannya Master adalah komponen yang menjadi titik utama dan slave adalah komponen yang bertindak atas perintah master.

dalam kasus ini *Microcontroller* kita adalah *Master*

dan oled 1.3 inch adalah *Slave*

setiap kali master ingin mengirimkan atau bahkan meminta sesuatu kepada *Slave* maka master harus mengetahui alamat dari *Slave* tersebut, nah dibuat seperti itu karena dalam 1 jalur I2C dapat dipasangkan lebih dari 1 *Slave*

seperti ilustrasi pada gambar dibawah ini.

![Ilustrasi I2C](/assets/images/958JATMsu3.png)

alamat ini direpresentasikan dalam nilai bit biasanya dalam format 7 bit, seperti **0x01, 0x02 ... 0x3c ...**

dalam ilustrasi diatas ketika **Master** ingin melakukan komukasi dengan **Slave 1** maka master akan mengirimkan **Slave Address** yaitu **0x01**

### Control Byte

selanjutnya kita akan membahas soal **Control Byte** dalam control byte ini jika dilihat pada datasheet pada halaman 20 dijelaskan bahwa control byte berisi Co dan D/C bits yang diikuti 6 bit lainnya 0, jadi bisa 0b00000000 atau 0b01000000 atau 0b10000000 atau 0b11000000

![Control Byte](/assets/images/hIrJGNJY1Z.png)

dijelaskan bahwa jika

- jika **Co** / (Continuation bit) bernilai 0 maka data yang akan dikirimkan setelahnya (setelah control byte) akan dianggap hanya sebagai *bytes* data
- jika **D/C** (Data/Command) bernilai 0 maka data yang akan dikirimkan setelahnya (setelah control byte) akan dianggap sebagai *Command* (yaitu bit perintah) dan sebaliknya jika bernilai 1 maka data yang akan dikirimkan akan diaggap sebagai *bytes* data yang akan disimpan pada memeori ram IC Controller

### Data Byte

Dijelaskan di halaman 20 datasheet bahwa data bytes ini adalah data yang kita kirimkan ke IC Controller *data byte* akan dianggap sebagai data (yang akan disimpan ke dalam ram) atau sebagai *command* (perintah) bergantung dengan nilai **D/C** pada *Control byte* yang dikirimkan.

### Step 1 - Set Mux Ratio

Dalam *flow chart* dituliskan bahwa kita harus mengirim *bytes* 0xA8 dan 0x3F, jika kita lihat dalam *command table* di dalam datasheet pada halaman 31 maka dijelaskan bahwa 0xA8 adalah perintah/**Command** untuk mengatur *Multiplex Ratio*

![Multiplex Ratio](/assets/images/KYa0ZQHtdj.png)

terdapat 2 byte, byte pertama 0xA8 adalah paten yang artinya kita harus mengirim ini, dan bit berikutnya 0x3F adalah byte yang nilainya menyesuaikan dengan (yaitu dari A0 sampai A5) dengan jumlah baris OLED yang digunakan, di kasus ini kita pake 64 baris dan nilai yang harus kita berikan adalah 0x3F = 63, karena dimulai dari 0, yaitu dari 15-63 (nilai yang valid)

jadi ...
- kalo misal pake oled 128x32 maka nilai 0x3F ganti dengan 0x1F
- kalo misal pake oled 128x16 maka nilai 0x3F ganti dengan 0x0F

dan berikut adalah kode program setelah mengimplementasikan step 1

```c++
#include <Wire.h>

#define OLED_ADDRESS 0x3C

void setup() {
  Wire.begin(); // inisialisasi komunikasi I2C

  // step 1 set mux ratio
  Wire.beginTransmission(OLED_ADDRESS); // mulai pengiriman (kirim slave adddress)
  Wire.write(0x00); // Co=0, dan D/C=0 artinya kita akan mengirim command(perintah)
  Wire.write(0xA8); // set mux ratio
  Wire.write(0x3F); // kirim nilai mux ratio = 0x3f (63) = untuk 64 baris
  Wire.endTransmission(); // akhiri pengiriman (stop condition)
}

void loop() {

}
```

### Step 2 - Set Display Offset

Dalam *flow chart* dituliskan bahwa data bytes yang harus dikirimkan adalah 0xD3 dan 0x00, dan jika di liat pada halaman 38 pada datasheet dijelaskan bahwa nilai *offset* adalah nilai dimana data baris di ram akan dipetakan (dimapping) dimana dalam baris panel oled (di datasheet ini disebut COM)

![Set Offset](/assets/images/aMPMAqxopr.png)

mengirim **0x00** akan menyatakan bahwa data pada RAM baris pertama akan dipetakan di COM-0 (com dapat dikatakan sebagai baris dalam panel Oled)

karena kita memang tidak inggin memberikan **Offset** maka nilai yang dikirimkan adalah **0x00**

dan berikut adalah kode program setelah mengimplementasikan step 2

```c++

  Wire.write(0xA8); // set mux ratio
  Wire.write(0x3F); // kirim nilai mux ratio = 0x3f (63) = untuk 64 baris
  Wire.endTransmission(); // akhiri pengiriman (stop condition)

  // step 2 set Display Offset
  Wire.beginTransmission(OLED_ADDRESS); // mulai pengiriman (kirim slave adddress)
```

### Step 3 - Set Display Start Line

Dalam langkah ke 3 ini *byte* yang harus dikirimkan adalah 0x40, jika dilihat deskripsi perintah untuk Set Display Start Line pada datasheet halaman 36

![Set Display Start Line](/assets/images/yDPBZAcdn7.png)

singkatnya perintah ini adalah untuk mengatur pemetaan dimualainya alamat di **RAM**, berbeda dengan offset dimana digunakan untuk mengatur pemetaan di panel Oled.

struktur perintah ini dapat dilihat pada **Command Table** pada halaman 31

![Set Display Start Line](/assets/images/4QrpYy4uZJ.png)

dalam byte perintah ini terdapat 2 bit yang sudah paten ditentukan dan bit sisanya sebagai parameter yang diberikan
jadi Ox4x = 0b0100 0000 | (Nilai Start Line 0-63)

### Step 4 - Set Segment Remap

![Set Segment Remap](/assets/images/FZ9bYkFFgZ.png)

- jika diberikan nilai 0xA0 maka alamat kolom 0 akan dipetakan pada SEG0 pada panel OLED

hal ini bergantung pada rangkaian IC Controller dengan panel Oled, untuk yang sudah saya coba dengan modul oled yang tersedia dipasaran mereka memetakan address 0 pada SEG127 jadi nilai byte yang akan dikirmkan adalah 0x01 pada langkah 4 ini

# Langkah kirim data

sebagai percobaan berikut adalah kutipan program untuk mengirim data yang akan ditampilkan pada oled

```c++
// kirim pola catur
for (int page = 0; page < 8; page++) {
  for (int column = 0; column < 128; column++) {
    Wire.beginTransmission(OLED_ADDRESS);
    Wire.write(0x40); // Data mode
    // jika berada pada kolom/8 (genap) dan pada page genap atau pada kolom/8 ganjil dn page ganjil maka 0xff (pixel menyala)
    // jika bedada pada kondisi selain itu, berada pada kolom genap dan page ganjil atau pada kolom ganjil page genap maka pixel mati
    Wire.write(page % 2 == 0 ^ (column/8) % 2 == 0 ? 0xFF : 0x00);
    Wire.endTransmission();
  }
}
```

```c++
  Wire.endTransmission(); // akhiri pengiriman (stop condition)

  // step 6 set com pins configuration
  Wire.beginTransmission(OLED_ADDRESS); // mulai pengiriman (kirim slave adddress)
  Wire.write(0x00); // Co=0, dan D/C=0 artinya kita akan mengirim command(perintah)
  Wire.write(0xDA); // set com pins configurations
  Wire.write(0x02); // kirim A[4] = 0, A[5] = 0
  Wire.endTransmission(); // akhiri pengiriman (stop condition)

  // step 7 set contrast control
  Wire.beginTransmission(OLED_ADDRESS); // mulai pengiriman (kirim slave adddress)
  Wire.write(0x00); // Co=0, dan D/C=0 artinya kita akan mengirim command(perintah)
  Wire.write(0x81); // set contrast
  Wire.write(0x7F); // kirim nilai contrast (0x7F = 127)
  Wire.endTransmission(); // akhiri pengiriman (stop condition)

  // step 8 set disable entire display on
  Wire.beginTransmission(OLED_ADDRESS); // mulai pengiriman (kirim slave adddress)
  Wire.write(0x00); // Co=0, dan D/C=0 artinya kita akan mengirim command(perintah)
  Wire.write(0xA4); // set disable entire display on
  Wire.endTransmission(); // akhiri pengiriman (stop condition)

  // step 9 set Normal Display
  Wire.beginTransmission(OLED_ADDRESS); // mulai pengiriman (kirim slave adddress)
  Wire.write(0x00); // Co=0, dan D/C=0 artinya kita akan mengirim command(perintah)
  Wire.write(0xA6); // set normal display (tidak inverse)
  Wire.endTransmission(); // akhiri pengiriman (stop condition)

  // step 10 set osilator frequency
  Wire.beginTransmission(OLED_ADDRESS); // mulai pengiriman (kirim slave adddress)
  Wire.write(0x00); // Co=0, dan D/C=0 artinya kita akan mengirim command(perintah)
  Wire.write(0xD5); // set oscilator frequency
  Wire.write(0x80); // kirim nilai Divide ratio dan Oscilator Frequency
  Wire.endTransmission(); // akhiri pengiriman (stop condition)

  // step 11 set charge pump
  Wire.beginTransmission(OLED_ADDRESS); // mulai pengiriman (kirim slave adddress)
  Wire.write(0x00); // Co=0, dan D/C=0 artinya kita akan mengirim command(perintah)
  Wire.write(0x8D); // set charge pump
  Wire.write(0x80); // aktifkan charge pump
  Wire.endTransmission(); // akhiri pengiriman (stop condition)

  // step 12 display On
  Wire.beginTransmission(OLED_ADDRESS); // mulai pengiriman (kirim slave adddress)
  Wire.write(0x00); // Co=0, dan D/C=0 artinya kita akan mengirim command(perintah)
  Wire.write(0xAF); // set display On
  Wire.endTransmission(); // akhiri pengiriman (stop condition)
  
  // ############################################ 
  
  // Set Addressing Mode
  Wire.beginTransmission(OLED_ADDRESS); // mulai pengiriman (kirim slave adddress)
  Wire.write(0x00); // Co=0, dan D/C=0 artinya kita akan mengirim command(perintah)
  Wire.write(0x20); // set addressing mode
  Wire.write(0x00); // set addresing mode horizontal
  Wire.endTransmission(); // akhiri pengiriman (stop condition)
  
  // Set Page Address Range
  Wire.beginTransmission(OLED_ADDRESS); // mulai pengiriman (kirim slave adddress)
  Wire.write(0x00); // Co=0, dan D/C=0 artinya kita akan mengirim command(perintah)
  Wire.write(0x22); // set page address range
  Wire.write(0x00); // set page start (mulai dari page alamat 0x00)
  Wire.write(0x07); // set page start (selesai page page alamat 0x07)
  Wire.endTransmission(); // akhiri pengiriman (stop condition)

  // Set Column Address Range
  Wire.beginTransmission(OLED_ADDRESS); // mulai pengiriman (kirim slave adddress)
  Wire.write(0x00); // Co=0, dan D/C=0 artinya kita akan mengirim command(perintah)
  Wire.write(0x21); // set kolom address range
  Wire.write(0x00); // set kolom start (mulai dari kolom alamat 0)
  Wire.write(0x7F); // set kolom end (selesai page kolom alamat 127)
  Wire.endTransmission(); // akhiri pengiriman (stop condition)

  // kirimkan data pola catur
  for (int page = 0; page < 8; page++) {
    for (int column = 0; column < 128; column++) {
      Wire.beginTransmission(OLED_ADDRESS);
      Wire.write(0x40); // Data mode
      Wire.write(page % 2 == 0 ^ (column/8) % 2 == 0 ? 0xFF : 0x00);
      Wire.endTransmission();
    }
  }
}
```
